# Synthetic previews

`progress.en.png` and `progress.ru.png` render the actual
`format_download_progress` output for a generated title, 4 GiB total, 55% received,
2 MiB/s and 920 seconds remaining. A minimal local HTML shell adds demonstration
Pause/Refresh buttons. They illustrate message content, not an exact Telegram theme.
No network request, live account, personal torrent, chat ID or embedded private
metadata was used. Inspect both images when changing message layouts.
