# Установка

Для паузы и продолжения нужен qBittorrent **5.x**; общий стек проверен с **5.1.2**. Диагностика отклоняет другие основные версии.
Нужны Docker Engine/Desktop и Compose v2. Проверяемая платформа — Linux amd64.
Все команды выполняются из корня проекта.

## Бот, qBittorrent и Jackett вместе

```sh
cp .env.example .env
cp bot.env.example bot.env
chmod 600 .env bot.env
mkdir -p downloads
```

В `.env` укажите владельца папки загрузок: `PUID`/`PGID` из `id -u` и `id -g`.
`DOWNLOADS_DIR` должен указывать на доступную для записи папку. Если порты заняты,
измените порты веб-интерфейсов и соединений с пирами.

Сначала запустите сервисы; данные бота пока могут оставаться пустыми:

```sh
docker compose up -d qbittorrent jackett
```

1. Откройте `http://localhost:8080`. Временный пароль qBittorrent для `admin`
   находится в `docker compose logs qbittorrent`. Просмотрите его локально;
   не публикуйте журнал. Задайте постоянный пароль в настройках веб-интерфейса.
2. Откройте Jackett: `http://localhost:9117`. Добавьте нужные индексаторы,
   скопируйте API-ключ в `bot.env`. Учётные записи трекеров остаются только у вас.
3. Создайте бота через BotFather. В `bot.env` укажите токен, разрешённые числовые
   Telegram ID через запятую, логин/пароль qBittorrent и API-ключ Jackett.
   Все разрешённые пользователи управляют общей библиотекой торрентов.
4. Значения с `$`, `#` или пробелами заключайте в одинарные кавычки; внутреннюю
   кавычку экранируйте как `\'`. Файлы `.env` и `bot.env` нельзя публиковать.

```sh
docker compose build bot
docker compose run --rm --no-deps bot python -m qbitbot.cli.setup_check
docker compose up -d
```

Проверка авторизуется в API и проверяет доступ к папке состояния, не запуская
опрос Telegram и не добавляя торренты. Исправьте указанные ошибки перед запуском.
Не публикуйте вывод `docker compose config`: он содержит значения паролей.
В Telegram откройте `/start` и проверьте Поиск, Загрузки и Состояние.
Бот выбирает английский или русский по языку Telegram. Команда `/language` сохраняет выбор языка.

Веб-интерфейсы по умолчанию доступны только локально. Для удалённого сервера
используйте SSH-проброс портов либо укажите конкретный LAN-адрес в
`WEB_BIND_ADDRESS`. Значение `0.0.0.0` открывает доступ на всех интерфейсах;
не выставляйте административные интерфейсы напрямую в Интернет.

## Уже установленные сервисы

Скопируйте `bot.env.example` в `bot.env`, задайте доступные из контейнера адреса
`QBIT_URL` и `JACKETT_TORZNAB_URL`, пароли и список пользователей. `localhost`
внутри контейнера означает сам контейнер. `QBIT_SAVEPATH` — путь внутри qBittorrent.

```sh
docker compose -f compose.bot-only.yaml build
docker compose -f compose.bot-only.yaml run --rm bot python -m qbitbot.cli.setup_check
docker compose -f compose.bot-only.yaml up -d
```

Запускается только бот. Не запускайте два экземпляра с одинаковым Telegram-токеном.

## Сохранение данных

`docker compose down` сохраняет именованные тома. Для обновления пересоздавайте
контейнеры с прежними томами. **`down -v` удаляет тома состояния и конфигурации**
и не подходит для обновления. Файлы загрузок хранятся в указанной папке хоста.
Резервные копии настроек и баз данных должны оставаться приватными. Не копируйте
работающую SQLite-базу как обычный файл; используйте согласованный снимок.
