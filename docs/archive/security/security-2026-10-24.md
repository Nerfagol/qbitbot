urllib3 2.8.0. Development pins include pytest 9.0.3 and its newly required

The bot base and CI use Python 3.12.15. Image digests are listed in
[Container inputs](../../deployment/images.md). The build uses pip 26.2.2 and removes it after
installation: even the newer installer vendors libraries with their own advisory
findings, and the running bot does not need a package installer.

Bundled services were refreshed to qBittorrent 5.3.0 and Jackett v0.24.2900.
qBittorrent's newer API returns HTTP 204 with an empty body on successful login
and mutations. Runtime and setup diagnostics now accept that response while
retaining legacy HTTP 200/`Ok.` authentication and rejecting failure responses.
Exact-hash addition verification and access/identity/confirmation controls remain.

## Remaining security findings

Trivy 0.76.1 used the vulnerability database updated 2026-10-24 at 07:11 UTC.
Counts below are package/advisory records, not distinct exploitable defects.
No vulnerability ignore rules or severity exclusions were used.

| Image | Critical | High | Medium | Low | Unknown |
| --- | ---: | ---: | ---: | ---: | ---: |
| Bot, Debian 13.7 | 0 | 44 | 58 | 61 | 1 |
| qBittorrent 5.3.0 | 0 | 1 | 0 | 0 | 2 |
| Jackett v0.24.2900 | 0 | 1 | 0 | 0 | 2 |

The bot has **zero Python package findings** after removing build-only pip.
Its Debian records have no fixed version listed in this database. The 44 high
records represent eight distinct IDs across source-package-related binaries:
CVE-2025-69720, CVE-2026-16742, CVE-2026-54369, CVE-2026-76642,
CVE-2026-78408, CVE-2026-78409, CVE-2026-78410 and CVE-2026-9538.
Several concern tools/services the bot does not invoke, such as privileged mount
operations or systemd-homed. Complete reachability was not established; absence
of a listed fix is not evidence of safety.

**Both current upstream service images still need package fixes.** They contain
`brotli-libs` 1.2.0-r1 (CVE-2026-111497, high in the Alpine feed) and musl/musl-utils
1.2.6-r2 (CVE-2026-107891, severity unknown; scanner lacks full advisory details).
The official Alpine 3.24 x86_64 package index already offers brotli-libs 1.2.1-r0
and musl/musl-utils 1.2.6-r3. The image rebuild dates precede those fixes.
Use patched upstream image rebuilds, or deliberately maintained derived images,
and rerun scans and stack tests before treating the bundled stack as remediated.
These findings were not suppressed or silently patched at container startup.

The old qBittorrent image had 489 records including four critical and 136 high;
the old Jackett image had 25 records including two critical and 16 high. The new
pins reduce exposure substantially but do not clear the remaining findings.

Dockerfile configuration scanning also reports root runtime user (DS-0002,
high) and missing Dockerfile HEALTHCHECK (DS-0026, low). Moving existing state
volumes to an unprivileged runtime needs an explicit ownership/migration design;
this maintenance does not change those permissions. External URL/redirect
restrictions and bounded search response bodies remain separate hardening work.
