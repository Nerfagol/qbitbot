# Устранение неполадок

## Бот не отвечает

Выполните `docker compose ps`, затем
`docker compose run --rm --no-deps bot python setup_check.py --language ru`.
Проверьте токен BotFather и числовой Telegram ID в обязательном `ALLOWED_USERS`.
Один токен должен использовать только один запущенный бот. Имена команд одинаковы
для обоих языков. `/start` открывает подсказку, `/language` сохраняет выбор языка.

## Сервис недоступен

В общей сети используйте имена `qbittorrent` и `jackett`. `localhost` внутри бота —
сам контейнер. Для режима только бота задайте доступные из его сети адреса.
Временный пароль qBittorrent меняется после перезапуска: задайте постоянный пароль
в веб-интерфейсе и обновите `bot.env`. Для Jackett нужны API-ключ и настроенные
индексаторы. Сохраните привязку веб-интерфейсов к loopback; для сервера без экрана
используйте SSH-туннель из инструкции установки.

Диагностика показывает безопасные имена полей и категории ошибок. Не публикуйте
вывод Compose с настройками, журналы сервисов, URL с ключами, env-файлы или копии БД.

## Нет результатов или загрузка ожидает

Настройте и проверьте индексаторы в Jackett. Бот отличает отсутствие совпадений от
недоступности источников; исправный API Jackett не гарантирует работу трекеров.
Сбросьте фильтры качества/размера. Рекомендованная сортировка предпочитает качество
среди раздач с достаточным числом заявленных источников, но это не гарантирует peers.

Получение метаданных, проверка файлов, ожидание источников и пауза — разные состояния.
Откройте подробности и нажмите обновление. После длительного отсутствия прогресса
бот предлагает новый поиск, не заменяя торрент автоматически. Все разрешённые
пользователи управляют всей библиотекой qBittorrent. Удаление означает торрент
**вместе с файлами** и требует подтверждения с названием.

## Устарели данные прогресса или состояния

Подписки сохраняются в SQLite и переживают перезапуск. Карточки состояния обновляются
ежечасно и показывают время UTC. Остановленный бот не может обновить свою карточку.
Проверки в пределах 30 секунд используют общий результат. Статус источников берётся
из последнего поиска, а не из ежечасного запроса ко всем индексаторам. Удалённая
карточка создаётся заново; заблокированные и исключённые пользователи не получают
дальнейших обновлений.

Проверьте права тома состояния при ошибках сохранения. Сохраняйте все три БД при
обновлениях; см. [копирование и восстановление](backup.ru.md). Уведомления могут
повториться после сбоя. Смена языка влияет на будущий текст, но не переписывает
уведомления, уже ожидающие доставки.

## Проверенное окружение

Автоматически проверены контейнеры Linux amd64. Другие архитектуры, удалённый Docker,
живые аккаунты трекеров и реальная доставка Telegram для публичной версии не прошли
приёмку. Тестовому окружению нужен Compose 2.24.4+ с `!override`; обычные файлы
установки этот тег не используют.
